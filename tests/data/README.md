# Test fixture data

`prime_mouse_ileum_tiny/` is a subset of the "tiny" Xenium Prime 5K mouse ileum example
bundle published by 10x Genomics (Xenium Mouse 5K Pan Tissue & Pathways Panel, fresh
frozen, Xenium Onboard Analysis 3.0; 23 cells, 5006 genes). Files not needed by the test
suite were removed; the remaining files are unmodified.

Source: 10x Genomics datasets, https://www.10xgenomics.com/datasets
